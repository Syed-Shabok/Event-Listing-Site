## Overview

The **Event Listing Platform** is a full-stack web application where users can browse, track, and manage events in Bangladesh. It includes features like user authentication, event tracking, and a modern responsive UI.

This project is built with **React**, **TailwindCSS**, **DaisyUI**, and **Node.js/Express** with **MongoDB** as the backend.

---

## Features

- ✅ **User Registration & Login** with JWT authentication
- ✅ **Browse Events** by category, date, and location
- ✅ **Track / Untrack Events** to save favorite events
- ✅ **View Tracked Events** for each user
- ✅ **Responsive Design** for mobile, tablet, and desktop
- ✅ **Cloudinary Image Upload** for event images
- ✅ **Secure Backend** with hashed passwords using bcrypt
- ✅ **RESTful API** for frontend consumption

---

## Tech Stack

### Frontend
- React 19
- React Router DOM
- React Hook Form
- React Hot Toast
- Zustand (State Management)
- TailwindCSS + DaisyUI
- Axios for API calls
- Vite as the build tool

### Backend
- Node.js & Express.js
- MongoDB & Mongoose
- JWT for authentication
- Bcrypt for password hashing
- Cloudinary for image storage
- CORS & cookie handling
